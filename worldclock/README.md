# WorldClock

A tiny world clock widget for Windows 10/11. A single ~70 KB exe with no installer and no runtime.
It only wakes up once a minute (once a second if seconds are shown), so CPU use stays at about 0% and RAM at a few MB.

## Use
- Put `WorldClock.exe` in any folder and run it. `WorldClock.ini` is created next to it the first time.
- **Left-drag** moves the widget. Its position is saved.
- **Right-click** opens the menu: Always on top, Show seconds, 24-hour clock, Opacity, Edit cities, Reload, Start with Windows, Exit.
- Times between 20:00 and 07:00 are shown in blue. The small line under each city shows the date there and its offset from your local time.

## Cities
Pick "Edit cities..." from the menu. Each line looks like this:

    Clock2=New York,Eastern Standard Time

Leave the zone empty to show local time. To list the valid zone IDs, run `tzutil /l` in a command prompt.
Up to 16 clocks. The widget picks up the file a moment after you save it.

## Build
`./build.sh` (mingw-w64). Source: `worldclock.c`. The icon is generated by `mkicon.py`.
